# Hackathon T&Cs — the rules that matter for building/submitting

Distilled from the official Términos y Condiciones (ISD + Tether/QVAC, Sep 9–11 2026, remote). The Spanish T&C text is the only binding version.

## Deadline & submission

- **Cierre de entregas: Sep 11, 08:00 Panama time (UTC-5). No extension — the platform closes automatically.** Build window: Sep 9 08:00 → Sep 11 08:00.
- Two deliverables, both required:
  - **Repo** accessible to the jury for the entire evaluation period. Open license not required.
  - **Demo video ≤ 5 min, in Spanish**, any hosting, link must work **without credentials**. It's the first thing judges review.
- Evaluation/voting Sep 11 08:00–14:00; awards 14:00+. In-person attendance is optional and earns no points.

## Technical rule (art. 10)

- Solution must be built on **QVAC**; inference runs on-device or delegated peer-to-peer.
- **Cloud inference = direct disqualification** — no ranking, no corporate challenge, no prize, regardless of quality. Cloud for non-inference (UI hosting, non-sensitive storage, auth) is fine.
- AI coding assistants are explicitly allowed.
- The substantial product must be built inside the 48h window. Libraries, public templates, OSS are allowed — but **every preexisting base must be declared in the README; omitting it disqualifies**.

## Disqualification causes (art. 25)

- Cloud inference routing
- Undeclared preexisting base in README
- Late or incomplete delivery
- Conduct-code violations (plagiarism, sabotage, unauthorized access to other teams' work, harassment)
- False registration data / impersonation

## Prizes & judging

- Podium: 3,000 / 2,000 / 1,000 USDT. Each corporate challenge: 1,500 USDT decided by that company's judge. Total 12,000 USDT.
- **Prizes are accumulable** — a team can win a podium spot AND multiple corporate challenges; any team may attempt any challenge, no pre-registration.
- Weights: Technical 35% (genuine QVAC use + implementation quality), Innovation 25%, Impact 20%, Design 10%, Completion 10%. Ties: Technical → Impact → jury president vote. Decisions are final/unappealable.
- Judges can leave positions/corporate challenges unawarded if nothing meets the technical bar.

## IP

- The team keeps all IP. Sponsors get visibility + preferred access to their challenge's entries, nothing more. Any later deal is negotiated directly.
- The demo video grants ISD/Tether a perpetual promotional license (affects the video only, not the solution).
